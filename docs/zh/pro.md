# Pro & Premium 许可证

CineRename 可以免费下载，并且在不付费的情况下可以**无限期使用**，但在 Studio 中每天最多只能重命名 2 个文件。

然而，对于高级用户、NAS 服务器管理员以及希望自动化整个流水线的用户，我们提供了 **Pro 许可证**。

## 解锁的功能

### 1. OpenSubtitles 字幕
Pro 版解锁无限字幕搜索和字幕自动化。它可以为整个文件夹批量搜索 OpenSubtitles，在下载前预览候选字幕，并在需要时使用 offset 或 drift timing 工具。

### 2. 重复项追踪
如果您有一部电影的多个版本（1080p, 4K，不同的编码），Pro 版的重复项模块会自动检测输出名称的冲突，并允许您一键分析、评分和清理过时的版本。

### 3. 自动模式 (CLI & GUI)
这是 Plex 服务器的“圣杯”。Pro 版允许使用“流水线”模式，该模式将以下操作连接在一起：**重命名 → 字幕 → 清理 → 移动**。此模式可在软件内使用，但主要通过 CLI 命令 `cinerename auto` 调用，使该软件能完美集成到 Radarr、Sonarr 或 NAS 的 cronjob 中。

## 如何激活许可证

1. 访问 [定价页面](https://cinerename.app/#pricing) 并购买您选择的 Pro 版本。
2. 您将通过电子邮件收到一个**许可证密钥**（由 LemonSqueezy 管理）。
3. 打开 CineRename，进入 **设置 → Pro 许可证**。
4. 粘贴您的许可证密钥并点击 **激活**。

应用程序将在验证密钥并立即解锁灰色的模块。验证成功后，应用程序会缓存验证状态：即使您断开互联网，它也将继续工作（透明的定期验证机制）。

## 常见问题 (许可证)

**如果升级到 Pro，我会丢失我的数据吗？**
不会，历史记录和 SQLite 数据库保持完全一致。许可证只是解锁了界面中的按钮。

**如果我更换电脑会怎样？**
您可以通过设置在旧设备上停用许可证，这将为您的新电脑腾出一个“名额”（在可用的 20 个名额中）。如果是磁盘损坏导致无法操作，LemonSqueezy 的网页控制面板允许您远程清除激活记录。
