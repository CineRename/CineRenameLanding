# 更新日志

此页面按从新到旧的顺序列出 CineRename 版本。请从主下载页面获取安装包。

## v0.5.5 - CineRename 0.5.5

发布日期 2026-10-15.

### 主要变化

- **macOS NAS / SMB 兼容性**：当网络卷不支持独占重命名时使用备用方案，覆盖暂存、完成、回滚和撤销操作。
- **复制到网络卷**：如果目标明确不支持保留 POSIX 权限，复制仍可继续；实际的访问权限错误和输入输出错误仍会中止操作。
- **命名模板**：支持 `{ title }` 等标签内部的空格，并保留媒体标题中看起来像模板标签的文字。
- **媒体技术信息**：修正 NV12 等格式以及原始位深未知时的视频位深识别。
- **字幕同步**：修复大幅时间偏移导致的溢出，并提高长时段字幕漂移校正的精度。
- **压缩包缓存**：避免缓存标记中的超范围时间戳导致清理崩溃。
- **安全性**：更新 TLS 和前端依赖，并禁止钩子及 Plex/Jellyfin 刷新请求自动跟随重定向，以保护身份验证数据。请直接配置服务的最终地址。
- **性能**：减少路径自然排序和命名模板渲染时的内存分配。
- **使用统计**：恢复网站到应用的来源归因，并新增页面和设置导航事件。

## v0.5.4 - CineRename 0.5.4

发布日期 2026-09-13.

### 主要变化

- 西班牙语与简体中文全量本地化：完整的界面语言支持、系统语言自适应以及对应语言的字幕检索支持。
- 群晖 Synology NAS 与 Docker 兼容性：修复不支持 Landlock 的旧版内核上循环崩溃的问题，确保 WebUI（8787 端口）顺利启动。
- Windows UNC 网络共享路径修复：彻底解决网络共享文件夹（\\server\share）重命名时误报“文件不再可用”的问题。
- 长路径支持与云盘兼容：原生支持超过 260 字符的 Windows 超长路径，增强 OneDrive 和 Dropbox 等云同步目录的兼容性。

## v0.5.3 - CineRename 0.5.3

发布日期 2026-09-12.

### 主要变化

- 在所有支持的操作系统上原生且永久启用 MediaInfo 占位符（`{resolution}`, `{source}`, `{video_codec}`, `{audio_codec}`, `{audio_language}`, `{dynamic_range}`, `{bit_depth}`），彻底解除此前在 Windows 上的配置限制。
- 简化命名模板编辑器，提供全量技术占位符标签与即时实时预览，并精简高级设置界面。
- 引入持久更新通知系统，集成顶部通知横幅、侧边栏快捷组件及状态栏徽章，支持一键便捷更新。
- 规范英法双语排版与语言细节（包括不换行空格、标准单双引号与专业影音术语一致性）。
- 全面更新便携版命令行 (CLI)、无头服务器 (Headless) 以及 NAS / Docker 部署的参考文档。

## v0.5.2 - CineRename 0.5.2

发布日期 2026-09-03.

### 主要变化

- 提升监控文件夹的容错能力：断开连接的驱动器或不可用的路径不再阻止后台监控或文件夹管理。
- 彻底消除手动下载字幕、自动模式以及重命名附加字幕时的无限重复导入循环。
- 优化后台通知与交互：检测到新媒体文件时不再强制切换页面，并保留正在进行的审核对话框。
- 修复字幕预览对话框中的无限加载状态与无法关闭的问题。
- 优化 Studio 工具栏布局，提供清晰的批处理状态计数，并完美对齐每行动作按钮。
- 修复下拉选择菜单在复合控件上的定位与屏幕溢出问题。
- 消除文件稳定性协调器在闲置状态下的 CPU 唤醒，提升能效。
- 在监控文件夹设置中新增直接在系统文件管理器中打开和自定义标签编辑功能。

## v0.5.1 - CineRename 0.5.1

发布日期 2026-09-02.

### 主要变化

- 当移动、复制或重命名被中断时，重命名任务更容易恢复和撤销。
- 提高历史记录可靠性，方便查看已完成操作并更安心地回滚。
- 改进内置更新器：加强签名校验，并在安装更新后更安全地重启应用。
- macOS 重要说明：仍在 0.5.0 的用户需要通过 DMG 或 PKG 手动安装 0.5.1；Windows 和 Linux 可继续使用内置更新。
- 让桌面应用、CLI、NAS 构建和 Docker 归档保持一致的重命名行为。
- 提升界面在日常使用中的稳定性。
- 提供更清晰的发布下载和校验文件，方便选择正确安装包并按需验证。

## v0.5.0 - CineRename 0.5.0

发布日期 2026-07-09.

### 主要变化

- 在真正修改文件前安全预览，批量重命名并整理电影、剧集和动画。
- 内置 Plex、Jellyfin 和 Kodi 命名配置，支持媒体文件夹和带 ID 的命名格式。
- 支持动画绝对集数编号、AniList/Kitsu 查询，以及可用时通过 TheTVDB 获取本地化集标题。
- 支持 dry-run 导出、重命名历史和 undo/rollback，降低整理大型媒体库的风险。
- 通过 OpenSubtitles 搜索字幕，支持语言选择、预览、格式转换和时间轴调整工具。
- 支持媒体库审计、NFO 生成、poster/fanart 下载，以及媒体服务器可用的元数据旁车文件。
- 支持监控文件夹、谨慎的自动流水线、qBittorrent / Transmission / JDownloader 集成和 Pre-Arr 工作流。
- 提供 headless CLI、WebUI、TUI、scheduler、NAS 压缩包和 Docker 归档，适合服务器环境。
