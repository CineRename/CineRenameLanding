# 更新日志

此页面按从新到旧的顺序列出 CineRename 版本。请从主下载页面获取安装包。

## v0.5.2 - CineRename 0.5.2

发布日期 2026-09-03.

### 主要变化

- 提升监控文件夹的容错能力：断开连接的驱动器或不可用的路径不再阻止后台监控或文件夹管理。
- 彻底消除手动下载字幕、自动模式以及重命名附加字幕时的无限重复导入循环。
- 优化后台通知与交互：检测到新媒体文件时不再强制切换页面，并保留正在进行的审核对话框。
- 修复字幕预览对话框中的无限加载状态与无法关闭的问题。
- 优化 Studio 工具栏布局，提供清晰的批处理状态计数，并完美对齐每行动作按钮。
- 修复下拉选择菜单在复合控件上的定位与屏幕溢出问题。
- 消除文件稳定性协调器在闲置状态下的 CPU 唤醒，提升能效。
- 在监控文件夹设置中新增直接在系统文件管理器中打开和自定义标签编辑功能。

## v0.5.1 - CineRename 0.5.1

发布日期 2026-09-02.

### 主要变化

- 当移动、复制或重命名被中断时，重命名任务更容易恢复和撤销。
- 提高历史记录可靠性，方便查看已完成操作并更安心地回滚。
- 改进内置更新器：加强签名校验，并在安装更新后更安全地重启应用。
- macOS 重要说明：仍在 0.5.0 的用户需要通过 DMG 或 PKG 手动安装 0.5.1；Windows 和 Linux 可继续使用内置更新。
- 让桌面应用、CLI、NAS 构建和 Docker 归档保持一致的重命名行为。
- 提升界面在日常使用中的稳定性。
- 提供更清晰的发布下载和校验文件，方便选择正确安装包并按需验证。

## v0.5.0 - CineRename 0.5.0

发布日期 2026-07-09.

### 主要变化

- 在真正修改文件前安全预览，批量重命名并整理电影、剧集和动画。
- 内置 Plex、Jellyfin 和 Kodi 命名配置，支持媒体文件夹和带 ID 的命名格式。
- 支持动画绝对集数编号、AniList/Kitsu 查询，以及可用时通过 TheTVDB 获取本地化集标题。
- 支持 dry-run 导出、重命名历史和 undo/rollback，降低整理大型媒体库的风险。
- 通过 OpenSubtitles 搜索字幕，支持语言选择、预览、格式转换和时间轴调整工具。
- 支持媒体库审计、NFO 生成、poster/fanart 下载，以及媒体服务器可用的元数据旁车文件。
- 支持监控文件夹、谨慎的自动流水线、qBittorrent / Transmission / JDownloader 集成和 Pre-Arr 工作流。
- 提供 headless CLI、WebUI、TUI、scheduler、NAS 压缩包和 Docker 归档，适合服务器环境。
