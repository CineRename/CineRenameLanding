# 重复项

**重复项**模块会扫描您的媒体库，找出同一部电影或剧集的多份副本，并帮助您保留最佳版本以释放空间。

## 工作原理

1. 您指向一个或多个文件夹。
2. CineRename 对所有视频文件进行索引，计算质量分数，并按媒体身份进行分组（电影按“标题+年份”，剧集按“剧集名+季数+集数”）。
3. 结果以**簇 (clusters)** 的形式显示：一个簇 = 指向相同内容的多个文件。

![重复项簇预览](/assets/img/duplicates-clusters.png)

## 质量分数

每个文件都会基于以下因素获得一个分数：

- **分辨率** — 4K > 1440p > 1080p > 720p > 480p
- **编解码器** — HEVC/AV1（高效率），旧编解码器会有减分
- **片源** — BluRay > WEBRip > HDTV > DVDRip
- **码率 (Bitrate)** — 在分辨率相同的情况下，高码率会有加分
- **音频** — DTS-HD MA / TrueHD > DTS / DD+ > AC3 / AAC
- **大小** — 在技术质量相同的情况下作为决胜条件

得分最高的文件会被标记为**保留**，其余的则标记为**待删除候选项**。

::: tip 没有自动删除
未经您的明确同意，绝对不会删除任何文件。该模块只提供**建议**。
:::

## 上下文菜单

在簇的每一行上，**右键单击**会打开：

- **打开位置** — 在系统原生的访达 (Finder) / 资源管理器 (Explorer) 中打开
- **播放视频** — 启动默认播放器
- **强制保留** — 将此文件标记为“保留”（覆盖默认评分机制）
- **强制删除** — 标记为删除
- **从簇中排除** — 如果 CineRename 发生了错误分组

## 批量删除

当您对所有簇做出了决定后，点击**删除标记项 (Delete marked)** 按钮：

1. 将请求最后一次确认
2. 将文件移动到系统回收站（可恢复）
3. 在**历史记录**中记录该操作（用于撤销）

::: warning NAS 用户请注意
删除操作通过操作系统的回收站进行。如果您的 Synology 或 QNAP 尚未启用**网络回收站 (SMB/CIFS)**，文件将被永久删除。在使用批量删除之前，请确保在您的 NAS 共享文件夹上启用了“启用回收站”选项。
:::

## 最佳实践

- **始终先重命名** — 否则 CineRename 很难将 `MovieX.1080p.x264-GROUP.mkv` 与 `MovieX.4k.HDR.mkv` 匹配，因为它们的名称看起来完全不同。
- **先进行一次试运行 (dry-run)** — 探索各个簇，调整覆盖设置，然后再执行删除。
- **检查多重版本** — 对于电影，“导演剪辑版 (Director's Cut)”、“加长版 (Extended)”、“剧场版 (Theatrical)”如果被明确命名，则**不会**被视为重复项。

## 已知限制

- 对于**多碟片**（一部电影被切割为 `Movie - cd1.mkv` + `Movie - cd2.mkv`），CineRename 只有在遵循 `cd1`/`cd2` 或 `part1`/`part2` 约定的情况下才能正确地将它们分组。
- 对于**混合压缩包**（包含多个版本的 zip 文件），您必须先解压它们或使用 Studio 对它们进行规范化。
